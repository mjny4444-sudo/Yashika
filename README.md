# Yashika's Birthday Website 🌷💗

A personalised romantic birthday website with 10-photo scrapbook, a long personal love letter, relationship quiz, gift reveal, birthday cake, confetti, and optional music.

## Run in VS Code
1. Download and extract the ZIP.
2. Open the `yashika_birthday_website` folder in VS Code.
3. Install the **Live Server** extension (if needed).
4. Right-click `index.html` → **Open with Live Server**.

## Add your 10 photos
Put your pictures in the `images` folder and name them exactly:
`photo-01.jpg`, `photo-02.jpg`, `photo-03.jpg`, `photo-04.jpg`, `photo-05.jpg`,
`photo-06.jpg`, `photo-07.jpg`, `photo-08.jpg`, `photo-09.jpg`, `photo-10.jpg`.

The first photo appears in the opening section and again in the scrapbook.
If your images are PNG/WEBP, update the matching `.jpg` names in `script.js` and the hero image path in `index.html`, or convert the images to JPG.

## Personalise the website
Open `script.js`:
- `memories`: change photo captions.
- `loveLetter`: edit the letter to make it sound even more like you.
- `quizQuestions`: change the questions and answers to your own inside jokes.
- `giftText`: edit the gift/date reveal.

## Optional music
Add an audio file you have permission to use as `audio/our-song.mp3`. She needs to tap the music button to start playback.

## Sharing it
The site runs locally first. To send her a link, publish the folder using GitHub Pages or Netlify. Remember that published links may be accessible to anyone who has the URL, so only include photos and personal details you're comfortable sharing.
